Requisitos do Sistema

Objetivo

O nosso TaskFlow é uma aplicação simples com o objetivo de organizar tarefas. O sistema será executado no navegador e não utilizará banco de dados.

Requisitos Funcionais: 

-RF01: Adicionar tarefas: O usuário deve conseguir escrever o nome de uma tarefa e adicioná-la ao quadro.
-RF02: Listar tarefas: As tarefas cadastradas devem aparecer na tela para o usuário.
-RF03: Concluir tarefas: O usuário deve conseguir marcar uma tarefa como concluída.
-RF04: Avisar quando não houver tarefas: Caso não exista nenhuma tarefa cadastrada, o sistema deve mostrar uma mensagem informando que a lista está vazia.
-RF05: Atualizar contadores: O sistema deve atualizar a quantidade de tarefas exibida no quadro quando uma tarefa for adicionada ou conclúida.

Requisitos Não Funcionais:

- A aplicação deve ser desenvolvida com HTML, CSS E JavaScript.
- A aplicação deve funcionar em navegadores normais, como Google Chrome, Edge ou Firefox.
- Não será necessario utilizar banco de dados.
- A interface deve ser simples e de fácil entendimento.
